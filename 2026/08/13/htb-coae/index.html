Before all

老樣子 先上個人權
https://academy.hackthebox.com/achievement/badge/03e8b835-91c3-11f1-82d1-bea50ffe6cb4

前一張 CWES 的心得 (LINK)，重複的會員購買規則和一些比較就不再贅述

因應最近看到得鬼故事給讀者一個訊息
所有 HTB 證照持有者都該拿得出一個 HTB Academy Badge 連結以及一個 Credly 連結

今年年初看到 HTB 推出 COAE 的證照，是聚焦於 AI Security 的，同時間我也注意到了 Offsec 推出 OSAI 證照，感覺兩張證照有點對標效果（？）
根據網路上的說法，這兩張證照的差異感覺上是 HTB 的 COAE 除了一些 LLM 應用層（Agentic Apps/MCP） 上的攻擊或被講到爛掉的 Prompt Injections，更多是聚焦於 Model Attacks 像是最基本的 Label Flipping/Backdoor/Dataset Privacy 一路走向 Adverseral Models 的各種討論（基本的反向傳播、L0~L2 怎麼放不同權重迭代的訓練…） 和一些防守的討論（Guardrail, 師生模型…）；而 OSAE 則更聚焦於模型應用層以及打向內部環境的 Red Team 技巧

同樣是基於成本的考量 + 自己蠻喜歡摸跟數學相關的東西就決定去走完 COAE 的課程並考去證照

考證照前的準備

在上課前我就對常用的 ML Models 有基本的了解和掌握，也有手動做過一些 CNN/RAG 的實踐和專題，也大概知道會有哪些攻擊，所以整體而言看教材的時候和做 Lab 的時候還蠻舒服的（除了專有名詞不舒服 肯定是 Paper 讀少了X）
不過其實有基本的線性代數和微積分知識，看前面的教材（有個 Fundamentals of AI）以後能解釋出模型的原理是什麼的話我想應該是不會有什麼問題？

再續了一年 Silver Annual 會員，想到的時候就去打 HTB AI Red Teamer Path 的 Lab，如果總和在一塊算我總共做了多久大概是一到兩周吧？
其中 Sparsity Attacks 我覺得特別有趣，也是開始課程前沒看過的東西，是用來討論最少量（例如說像素）擾動來完成模型欺騙的對抗攻擊。像是 ElasticNet 就是利用 L1 + L2 距離來演化出一個擾動量較少的對抗模型。

而 Lab 則是會挑這類模型的攻擊案例/Papers（像是經典的 Adverseral Patch (LINK)，在教會你用必要的 pytorch/numpy 等套件語法和引入模型的方法以後，要自己寫腳本完成攻擊/Train。

對我自己沒什麼問題的一部分是 MCP/Agentic Tools 的攻擊，去多瞭解個 API 或把 Prompt Injection 結合 Web Recon 和常見攻擊和通靈防護等等的對一個主業 Web 狗（好吧…鯨）而言肯定小問題，不過如果有人衝著 AI 安全在只會 AI 的情況下來考這張證照可能反而會敗在這邊 QQ，考前大概就能預言 HTB 會在這邊稍微搞點事
然後要記得 LLM 是不穩定的，確認一個 Payload 正不正確建議送個五次以上（

最後完成課程的時候大力推薦要整理不同模型在課程中有提到的對應攻擊流程的大腳本，考試的時候可以很快在看到模型後上手修一下腳本就完成解題。

正式考試

正式考試是一個七天多個 lab 的環境，你要拿到九十分以上才能通過（等於只有某一把特定的 flag 可以沒拿到）
然後一樣，考前強烈推薦去看一下 Sysreptor 這個報告模板以及生成工具怎麼使用 + 去讀一下 HTB Academy: Document and Report(LINK)，好好照這個寫比較不容易被退件
戳下去開始考試 拿到 Lab 環境，由於我覺得 AI Model (尤其傳統 ML) 蠻 deterministic 大概就是模型 <=> 攻擊 對應 + 不擔心 Web 攻擊的部分，所以沒特別計時 但最後大概是九小時就破台ㄌ

我只能說只要是 HTB 證照都有超綱的地方，不過這張證照超綱倒是呒超在 AI 模型本身，因為他的情境是在打一家公司的 PT，所以一定有些地方是需要做一些傳統 Web Recon/Exploit 和各種情資蒐集和通靈的成分在（再強調一遍，課程教材沒有）。一個心法就是看到的模型都可以打，然後如果有缺什麼那大概率就是要找什麼？

最後就是大概在三周後收到通過通知（好欸，就是比上次 CWES 四小時候通知慢了億點點），但也合理這張的評審數量應該是少很多的。

After all

總結一下，我覺得這張證照對有做過 ML 想要接觸這方面攻擊；或者對於數學底子不錯的一般資安人，想看一下這種未來新興攻擊面的人都是很棒的學習選擇，整體而言只要有好好看過課程和 LABS 我相信要 pass 應該也不會太難？
